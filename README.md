# DPFS_maximiliano_fernandez

## 🎸 Tienda de Guitarras y Accesorios

Este proyecto consiste en el desarrollo de un e-commerce dedicado a la venta de guitarras y accesorios para guitarristas de distintos niveles.

El sitio ofrece una selección curada de guitarras eléctricas, acústicas y criollas, junto con accesorios esenciales como cuerdas, púas, correas, afinadores, fundas y capos.

El objetivo es brindar una experiencia clara y accesible, evitando la saturación de productos y facilitando la compra tanto para principiantes como para músicos intermedios.

---

## 👥 Público objetivo

- Personas que están dando sus primeros pasos con la guitarra.
- Guitarristas intermedios que buscan renovar accesorios o cambiar de instrumento.
- Usuarios que valoran una experiencia simple, estética y funcional.
